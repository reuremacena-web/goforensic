# GOForensic - Versão Estática Otimizada

## ✅ Status do Projeto

Esta é a versão estática otimizada do GOForensic, projetada para:
1. **Deploy Imediato**: Funciona sem configuração complexa de backend.
2. **Alta Performance**: Carregamento instantâneo no Vercel.
3. **Interface Profissional**: Design "Neo-Brutalist Professional" implementado.

## 🚀 Acesso

- **URL de Produção**: https://goforensic.vercel.app
- **Repositório**: https://github.com/reuremacena-web/goforensic

## 🛠️ Como Continuar Desenvolvendo

### 1. Fazer Alterações
Todas as alterações devem ser feitas na pasta `client/src`.
- `pages/`: Novas páginas
- `components/`: Novos componentes
- `index.css`: Estilos globais

### 2. Testar Localmente
O servidor de desenvolvimento está rodando em:
- **URL Local**: http://localhost:3000

### 3. Publicar Alterações
Para atualizar o site ao vivo, basta fazer um push para o GitHub:

```bash
git add .
git commit -m "Descrição da mudança"
git push origin main
```

O Vercel detectará automaticamente e fará o deploy em segundos.

## 🎨 Design System

O projeto segue a filosofia **Neo-Brutalist Professional**:
- **Fontes**: Space Grotesk (Títulos), Inter (Corpo), JetBrains Mono (Dados)
- **Cores**: Emerald Green (#10B981) sobre Branco/Cinza
- **Estilo**: Bordas definidas, sombras duras, alta densidade de informação
